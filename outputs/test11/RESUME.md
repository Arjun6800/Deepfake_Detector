## PowerShell commands

Run these setup commands from the local Windows machine. Repeat them in any new terminal used for a later stage.

~~~powershell
Set-Location -LiteralPath 'D:\Research\Deepfake_using_rPPG'
$repo = (Get-Location).Path
$python = Join-Path $repo '.venv\Scripts\python.exe'
$output = Join-Path $repo 'outputs\test11'
$env:PYTHONDONTWRITEBYTECODE = '1'
$env:OPENBLAS_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
$env:OPENCV_FFMPEG_THREADS = '1'
$env:MPLBACKEND = 'Agg'
~~~

Start extraction as an independent hidden Windows process. It can continue after closing Codex or PowerShell. Keep the computer awake.

~~~powershell
$stamp = Get-Date -Format 'yyyyMMdd-HHmmss'
Start-Process -FilePath $python -ArgumentList @('-u','-B','-m','deepfake_rppg.phase48_extract') -WorkingDirectory $repo -WindowStyle Hidden -RedirectStandardOutput (Join-Path $output "extract-$stamp.out.log") -RedirectStandardError (Join-Path $output "extract-$stamp.err.log") -PassThru
~~~

Inspect progress and recent failures.

~~~powershell
Get-Content -LiteralPath (Join-Path $output 'extraction_progress.jsonl') -Tail 10
Get-Content -LiteralPath (Join-Path $output 'extraction_failures.jsonl') -Tail 10
Get-Content -LiteralPath (Join-Path $output 'extraction_summary.json')
~~~

To **resume**, run the same extraction command above after the previous process has stopped. Completed feature checkpoints are validated and skipped. Completed observation checkpoints are reused even if feature extraction was interrupted. Failed or unfinished videos are retried. An OS file lock prevents two extraction runs from overlapping. The extractor stops scheduling work at 2 GiB free plus a 64 MiB write buffer, and workers check the same reserve during decoding and before writes. Free space on the workspace drive before resuming a disk-space pause. Only Phase 4.8 output checkpoints are written.

After the extraction summary records **600 completed videos**, launch nested classification.

~~~powershell
$stamp = Get-Date -Format 'yyyyMMdd-HHmmss'
Start-Process -FilePath $python -ArgumentList @('-u','-B','-m','deepfake_rppg.phase48_classify') -WorkingDirectory $repo -WindowStyle Hidden -RedirectStandardOutput (Join-Path $output "classify-$stamp.out.log") -RedirectStandardError (Join-Path $output "classify-$stamp.err.log") -PassThru
~~~

Once **classification_complete.json** has been generated by the completed classification run, generate evaluation tables, plots and the final report.

~~~powershell
& $python -B -m deepfake_rppg.phase48_evaluate
~~~

Run the regression suite independently if needed.

~~~powershell
& $python -B -m unittest discover -s tests -v
~~~

## Important decisions

- Selection is checked against the audited training rows at launch, with 50 complete source families and the original 96 clips retained. Source content is hashed before new capture. Existing Phase 4.5–4.7 artifacts are read-only. The 96 centered feature rows are reused. The full-length retained RGB archives support every available rPPG window. Older AU checkpoints contain centered summaries, so retained multi-window videos need a fresh AU-only pass. New clips use one combined RGB and AU pass.
- Keep one exact centered window for the 600-video replication. For multi-window videos, add complete eight-second windows at four-second hops and deduplicate the center if it is already on the hop grid. The temporal comparison uses the shared subset supporting at least two windows and evaluates fusion250 with center, mean, mean plus standard deviation, median, and mean of window scores.
- Five outer source-family folds and four inner folds are deterministic, with seed 480. All nine replication arms use the identical folds. The four fixed classifier types each search two parameter settings on inner folds. Preprocessing is fitted within the relevant fold. Window-model classifiers weight videos equally within each class and average held-out window scores before thresholding at 0.5. The missingness and nuisance probes are diagnostic arms. The nuisance probe uses motion, light and compressed bits per pixel; those fields remain outside the nine primary ablations.
- Confidence intervals resample family-level metrics and paired family-level changes. Reports include pooled video metrics, family variability, counts, per-manipulation metrics, and all/new/retained cohorts. Read the 42-family new-only results as the replication check. Final architecture selection remains pending the actual results.
- Extraction checkpoints contain compact data in **outputs/test11/checkpoints/**. Their keys incorporate the source identity and extractor signature. Editing signed inputs or extractor code invalidates matching checkpoints. Preserve previously signed code and input files while a run is in progress.
