# Run and resume Phase 4.10

Run from the project workspace in PowerShell using the existing environment.

~~~powershell
Set-Location -LiteralPath 'D:\Research\Deepfake_using_rPPG'
$python = '.\.venv\Scripts\python.exe'
$env:PYTHONDONTWRITEBYTECODE = '1'
$env:OPENBLAS_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
$env:MKL_NUM_THREADS = '1'
$env:NUMEXPR_NUM_THREADS = '1'
$env:MPLBACKEND = 'Agg'
~~~

Run the stages in order. Continue when the previous command exits successfully.

| Stage | Command |
| --- | --- |
| 1. Signal enhancement pilot, 96 videos | `& $python -u -B -m deepfake_rppg.phase410_run pilot` |
| 2. Pilot nested evaluation and shortlist | `& $python -u -B -m deepfake_rppg.phase410_run pilot-eval` |
| 3. Shortlisted feature extraction, 484 videos | `& $python -u -B -m deepfake_rppg.phase410_run extract` |
| 4. Nested classification | `& $python -u -B -m deepfake_rppg.phase410_run classify` |
| 5. Final tables, figures and report | `& $python -u -B -m deepfake_rppg.phase410_run report` |

Resume by running the same interrupted stage. Set the stage below to the one that
was interrupted.

~~~powershell
$stage = 'extract'
& $python -u -B -m deepfake_rppg.phase410_run $stage
~~~

A Windows file lock prevents overlapping stages. Completed feature and model-fold
checkpoints are written by atomic replacement and reused by revision. The matched
cohort also reuses the chosen variant's matching pilot checkpoints. Keep earlier
inputs and experiment code stable during execution. A code or input revision can
invalidate affected checkpoints. If the disk reserve triggers a pause, recover
free space before rerunning the same command. Output writes check a 2 GiB reserve
plus a 64 MiB margin. Progress shows elapsed wall time and ETA.

Optional validation commands were run during implementation.

~~~powershell
& $python -u -B -m deepfake_rppg.phase410_run audit
& $python -u -B -m deepfake_rppg.phase410_run smoke

~~~

Smoke artifacts are under `outputs/test13/smoke`. Final tables and figures are
generated by the stages above. Review the matched-cohort results before beginning
larger-scale work.
